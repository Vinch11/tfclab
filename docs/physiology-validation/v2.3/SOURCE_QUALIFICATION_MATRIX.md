Tous ces scalars sont volontairement conservés dans la même voie de stockage : cela démontre qu'elle ne détermine pas leur nature.

Dans la matrice de scalars stockés : **0,42 / score interne 0,95 / marge interne ±0,02** avant et après. La catégorie historique `test_labo` reste un identifiant de calcul, pas une méthode. Les tests liés et les estimations produites par le moteur gardent leurs propres heuristiques ; elles ne sont pas augmentées parce qu'une provenance documentaire est présente.

Les éventuelles incertitudes rapportées sont présentées séparément, avec source/fondement et statut non vérifié indépendamment. Un contexte documentaire complet n'est ni une validation hors échantillon ni une approbation individuelle. Aucun cas n'approuve une dose.
