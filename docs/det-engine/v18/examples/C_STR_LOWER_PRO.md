## Déroulement original

### Warm-up

8' : 5' vélo Z1 + activation (glute bridge 2×10, bird-dog 2×8/côté, squat PdC 2×10, mobilité cheville 1'/côté)

Zones sources : Z1

### Main

A) Back squat ou Goblet squat : 4×5 @ 80-85% 1RM (ou RPE 8) · tempo 3-1-1-0 · repos 2'30-3' entre séries.
B) Romanian deadlift : 3×6 @ RPE 7-8 · tempo 3-0-1-0 · repos 2'.
C) Bulgarian split squat : 3×6/jambe @ haltères modérés (RPE 7) · repos 90s.
D) Mollets debout (calf raise lourd) : 3×8 tempo 2-2-1-0 · repos 60s.

Zones sources : non déclarées

### Cool-down

8' : mobilité hanches (pigeon 1'/côté), psoas stretch (1'/côté), respiration nasale 3'

Zones sources : non déclarées

### Progression

Sem 1-2 : ancrer technique (RPE 7). Sem 3-4 : monter à RPE 8-8.5. Sem 5 : décharge -30% volume. Cycle 4+1.

Zones sources : non déclarées
