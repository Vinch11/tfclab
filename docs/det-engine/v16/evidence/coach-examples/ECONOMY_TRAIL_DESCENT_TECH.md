## Déroulement original

### Warm-up

15 min trot terrain plat + 5 min marche active côte

Zones sources : Z1, Z2

### Main

Exercices descente (Jornet method) : 1. Descente lente contrôlée — appui avant-pied, centre de gravité bas, regard 3-5m devant. 2. Descente libre rapide sur 100-200m — laisser les jambes aller, bras écartés pour équilibre. 3. Descente technique (pierres, racines) — lecture terrain, anticipation appuis. 4x5-8 min de descente à allure race simulation. Entre chaque : remontée Z2. Volume total : 400-600m dénivelé négatif.

Zones sources : Z2, Z3, Z4

### Cool-down

15 min terrain plat Z1 + étirements quadriceps

Zones sources : Z1
