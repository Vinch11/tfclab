## Déroulement original

### Main

Aucune séance. Le repos EST l'entraînement aujourd'hui — c'est pendant ces journées que les adaptations se construisent (réparation musculaire, consolidation neuro, baisse du cortisol).

Check-list du jour :
• Sommeil : viser 8-9h, coucher avant 23h. Pas d'écran 60' avant.
• Hydratation : 30-35 ml/kg/jour (≈ 2,2-2,5 L pour 70 kg). Urines couleur paille claire.
• Alimentation : protéines à chaque repas (1,6-2 g/kg/jour), glucides complets, légumes, oméga-3.
• Marche douce <20' tolérée si besoin de bouger (≠ entraînement).
• Étirements passifs très légers autorisés (10' max) sans recherche d'amplitude.
• Interdits : muscu, course, vélo, natation, HIIT, sauna intense, alcool.
