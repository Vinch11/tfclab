# Coach et Nolio : représentation, événement, prescription

Expérimental — DRAFT / NO-GO. Sources préservées, propositions non approuvées. Aucun appel réel Nolio, aucune donnée athlète.

[Bibliothèque hors ligne](coach-library.html) : 920 sources et 418 propositions. Les observations par modalité complètent le dossier sans effacer l’original. Les quatre revues documentaires du cycle 1 sont conservées.

Les 831 encodages texte historiques sont conservés comme représentations de revue ; ils ne constituent pas 831 événements prêts à transmettre. Le nouveau garde conserve séparément 75 fixtures de source mono-événement avec chronologie complète et 96 fixtures candidates. Il refuse la portée inconnue, les protocoles multi-jours et les bricks/mixed dans le contrat mono-sport actuel. Les instructions d’unité LCW nécessitent une clarification d’auteur. Les 13 fixtures structurées source et deux candidates restent des tests locaux avec ancres synthétiques, sans acceptation distante attestée.

Les 16 protocoles à actions multiples proviennent d’étiquettes de jours, J−n, matin/soir ou étapes ; une simple mention contextuelle du matin ou une alternative « J−7 ou J−10 » ne suffit pas. Les 27 questions initiales restent archivées. Ce garde expérimental ne reclassifie aucune erreur sportive historique pour la faire disparaître.

Les 2 425 variantes de source et les six liaisons paramétriques sûres V18 sont préservées, sans nouvelle instanciation complète par objectif. Aucun faux ID Nolio v2, API inventée, synchronisation ou conversion silencieuse multidisciplinaire. Une fixture texte ou structurée n’autorise aucune prescription ni écriture.

Le second audit a ensuite exécuté hors ligne les seules fonctions pures du chemin d’envoi inchangé et consulté deux pages publiques Nolio. Il révèle des limites supplémentaires, conservées séparément des succès du miroir local. [Détails, refus et sérialiseur expérimental non intégré](NOLIO_SOURCE_PATH.md).
