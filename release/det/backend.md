# Export Nolio du coach DET

`node release/det/build-nolio-backend.mjs <dossier>` prépare dans ce dossier un projet Supabase limité à DET. Il réutilise le client Nolio V2 du dépôt et le journal des opérations. Les fonctions se nomment `det-nolio-connect`, `det-nolio-callback` et `det-nolio-export`. Les tables et procédures de la migration portent le préfixe `det_nolio_v2_`, les index le préfixe `det_nv2_`. Les utilitaires de transport résident dans `det-nolio-export/lib`. Le calendrier de l’athlète est associé par le coach.

Sur le projet Supabase du site, appliquer la migration produite, puis déployer ces trois fonctions depuis le dossier préparé. Le projet doit disposer de `NOLIO_V2_CLIENT_ID` et `NOLIO_V2_CLIENT_SECRET`. Le callback enregistré pour cette application Nolio doit correspondre à `https://<projet>.supabase.co/functions/v1/det-nolio-callback`. Le coach autorise ensuite les droits de lecture et écriture des séances dans **Compte et athlète Nolio**. Les droits, les tokens et les créations sont conservés côté serveur.

**Exporter le plan**, **la semaine** et **la séance** archivent la version datée pour l’athlète sélectionné. Le serveur refait le précontrôle avec les références Nolio de cet athlète, compose les deux parties d’un enchaînement, puis utilise la simulation de Nolio avant chaque lot. Une sélection contenant une séance refusée bloque l’envoi de cette sélection. Une opération incertaine conserve son état dans le journal. Réessayer la même sélection réutilise les opérations déjà confirmées. La relecture finale compare les étapes des activités présentes dans Nolio. La réception matérielle se vérifie ensuite sur la montre appairée.

Sur la branche principale du site, le workflow GitHub **DET — déployer les fonctions Nolio** cible uniquement ces trois points d’entrée sur le projet de TFCLab 2.1. Il utilise le secret de déploiement Supabase du dépôt. La consultation de l’état HTTP démontre la présence du service. La preuve d’un envoi réel garde la date, la version de plan, la séance et les deux identifiants issus de l’écriture et de la lecture.
