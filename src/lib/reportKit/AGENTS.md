# Report diagram architecture

- Detailed sport diagrams live in `pedagogy.ts`: personal energy markers, six absolute effort zones, sport-specific TTE and stored early/late long-session comparisons. Values/targets come from `coachingCompass/reportPresentation`, zones and stored observations from `sportDiagramData`; running sensor speed is not relabelled when its unit is undocumented. Why: reports must be concrete and readable without inventing measurements, transferring bike metrics to running or changing prescriptions.- Athlete editions (`athlete: true`) show the objective range of the report gauges (`reportBrief` sections) instead of the compass target, show the shared VO₂max once in triathlon, never print engine/compass vocabulary, and read race intensity only from the zone engine's `race_specific` marker. Why: one athlete document must not show several targets for the same value or internal jargon.
